# Maybe · 未定设计室

一个关于设计意图变化的可交互概念原型。

## 体验

输入模糊的海报需求，选择一个草案，继续改方向，或使用“大胆跑偏”“再犹豫一下”“笑一个”。在“意图轨迹”中回看变化，并从某一步重新开始。选择草案后点击“带走灵感”可下载 SVG。

这是前端脚本驱动的原型，不连接 AI 模型，也不代表实证研究结果。所有开场内容为示例。对话和轨迹保存在浏览器 localStorage，清空浏览器数据会丢失。

## 本地运行

在项目目录运行：

```sh
python3 -m http.server 4173 --directory dist
```

访问 http://localhost:4173。无依赖安装或构建步骤。

## 文件

- `dist/index.html`：界面结构
- `dist/styles.css`：视觉和响应式样式
- `dist/app.js`：交互逻辑、意图记录和 SVG 海报模板
- `dist/assets/`：Fraunces 字体及其 OFL 授权
- `PRODUCT.md`、`DESIGN.md`：产品和设计记录

## 验证

验证过桌面和 390px 手机布局、草案选择、自由输入、主题变化、纠正理解、笑脸、历史恢复、刷新保留和 SVG 下载。未接入服务端模型或图片生成服务。
